RoutSurs is a downstream distribution based on Buildroot, and this manual is
derived from the Buildroot manual. The build engine described here is the
Buildroot build engine, so most of the documentation refers to Buildroot
behaviour and keeps the upstream terminology (`BR2_*` options, br2-external
trees, the Buildroot manual, ...).
